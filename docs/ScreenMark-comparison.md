# ScreenMark 功能对照

参考：[ScreenMark 官方产品页](https://ceritmustafa.github.io/screenmark-public/)，整理日期 2026-11-15。ScreenScribe 独立实现相似的 macOS 演示工作流，不承诺所有功能或交互完全相同。

| ScreenMark 功能 | ScreenScribe 对应 | 当前边界 |
| --- | --- | --- |
| 菜单栏入口与悬浮工具条 | 原生菜单栏控制面板与批注工具条 | macOS 26 Liquid Glass；macOS 15 原生材质回退 |
| 实时屏幕批注 | 透明屏幕覆盖层 | 以启动批注时选中的显示器为画布 |
| Freeze Frame | 捕获显示器并以静态画面批注 | 固定显示画面，底层程序继续运行 |
| 画笔 / 荧光笔 / 线条 / 箭头 / 图形 | 对应绘图工具与样式设置 | 不使用参考产品绘图引擎 |
| 原位文字编辑与移动 | 文字输入、选中、编辑与样式调整 | 中文输入应在真机复核输入法行为 |
| 撤销 / 重做 / 擦除 | 文档历史与橡皮擦 | 模型行为由单元测试覆盖 |
| Blur | 像素化遮挡 | 用于展示遮挡；不提供信息不可恢复保证 |
| 白板与黑板 | 独立纯色背景画布 | 当前显示器 |
| Spotlight / Flashlight | 聚光灯与指针高亮 | 软件绘制的屏幕覆盖效果 |
| Live Zoom / Follow Lens | 跟随指针的放大镜 | 未提供三个完整缩放模式 |
| Snip 与 PNG | 画布及选区导出、剪贴板 | 导出包含批注；不含工具条 |
| MP4 录制 | ScreenCaptureKit 视频与可选系统 / 麦克风音频，最高 4K / 30 fps | 需要系统权限；录制性能取决于分辨率与设备 |
| Break Time | 休息倒计时 | 无 PIN 锁定和背景音乐 |
| Hide Desktop | 壁纸覆盖层遮住桌面图标 | 不修改 Finder 偏好；动态壁纸按静态图像处理 |
| iPhone / iPad Remote | 暂未实现 | 无配套 iOS 应用或网络远控服务 |
| 自定义全局快捷键 | 设置中逐项录入组合键 | 提供占用提示；不保证参考产品全部快捷键可一一映射 |

## 验证范围

截至 2026-11-15 的实际验证结果：

| 检查 | 结果 |
| --- | --- |
| Debug / Release 构建 | 通过，Apple Silicon arm64 |
| 11 项 XCTest | 全部通过，含历史、几何、原生鼠标事件、文字内容与焦点、Retina 裁剪和像素遮挡方向 |
| ZIP 解压完整性 | 通过 |
| 解压后 `codesign --verify --strict` | 通过，本机 ad-hoc 签名；未进行 Apple 公证 |
| 原生应用交互 | 待真机验证；当前自动化环境在 `NSApplication.shared` 的系统应用注册阶段中止，未进入应用业务代码 |
| GitHub Actions | 已配置，尚未在远程执行 |

单元测试不能替代系统权限、真实输入法候选框、多显示器、视频声音、全屏应用与屏幕分享等交互验证。浏览器也无法运行原生 macOS 批注覆盖层。发布前应在真实 macOS 环境依次检查以下流程：

1. 冻结一个可滚动网页，批注过程中尝试滚动，确认展示画面保持固定；退出后网页正常使用。
2. 分别输入中文、英文、多行文字，重新编辑并调整样式，检查焦点及输入法候选框。
3. 使用所有绘图工具，检查选中、移动、缩放、撤销和重做，以及 Retina PNG 导出。
4. 在主屏、外接显示器和原生全屏应用上启动批注，确认显示器坐标、工具条位置与按键行为。
5. 开关系统音频与麦克风录制，播放 MP4，确认声音、批注和停止后的文件完整性。
6. 打开屏幕分享，验证分享目标能够捕获批注覆盖层；窗口分享与显示器分享的行为可能不同。

未完成上述真机检查的功能应标注为待验证；成功编译不代表所有系统交互已经验证。
